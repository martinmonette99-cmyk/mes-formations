# Cours 3 — Créer un sous-titre

## Objectif

À la fin de ce cours, tu sauras créer un sous-titre avec deux caractères `#`.

Nous ajoutons une seule nouvelle notion :

```markdown
## Mon sous-titre
```

---

## 1. Du titre principal au sous-titre

Dans le cours précédent, tu as appris à créer un titre principal :

```markdown
# Mon titre principal
```

Pour créer un sous-titre, tu places deux caractères `#` devant le texte :

```markdown
## Mon sous-titre
```

Il faut donc écrire :

1. deux caractères `#` ;
2. un espace ;
3. le texte du sous-titre.

---

## 2. La relation entre les deux titres

Le titre principal représente le sujet général du document.

Les sous-titres servent à diviser ce sujet en différentes parties.

Exemple :

```markdown
# Ma formation en développement web

## HTML

## CSS

## JavaScript
```

Dans cet exemple :

- `Ma formation en développement web` est le sujet général ;
- `HTML`, `CSS` et `JavaScript` sont trois parties de ce sujet.

On trouve généralement un seul titre principal dans un document, mais il peut contenir plusieurs sous-titres.

---

## 3. Comparaison avec HTML

Puisque tu connais déjà HTML, tu peux faire ce rapprochement :

| Markdown | HTML | Rôle |
| --- | --- | --- |
| `# Titre` | `<h1>Titre</h1>` | Titre principal |
| `## Sous-titre` | `<h2>Sous-titre</h2>` | Sous-titre |

Ce ne sont pas les mêmes langages, mais la hiérarchie est comparable.

## À retenir

```markdown
# Titre principal

## Sous-titre
```

- un seul `#` crée le titre principal ;
- deux `#` créent un sous-titre ;
- un espace sépare les `#` du texte.
