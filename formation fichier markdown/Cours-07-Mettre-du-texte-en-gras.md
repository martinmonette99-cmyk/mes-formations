# Cours 7 — Mettre du texte en gras

## Objectif

À la fin de ce cours, tu sauras mettre un mot ou une expression en gras.

Nous apprenons une seule nouvelle notion : placer **deux astérisques de chaque côté du texte**.

---

## 1. La syntaxe du gras

Pour mettre un texte en gras, écris :

```markdown
**texte en gras**
```

Le résultat affiché sera :

**texte en gras**

Les quatre astérisques servent d’instructions : deux ouvrent la mise en gras et deux la ferment.

---

## 2. Mettre un seul mot en gras

Tu peux entourer uniquement le mot à faire ressortir :

```markdown
Ce fichier est **important**.
```

Résultat :

Ce fichier est **important**.

---

## 3. Mettre plusieurs mots en gras

Tu peux aussi mettre une expression complète en gras :

```markdown
Je dois retenir **la ligne vide**.
```

Résultat :

Je dois retenir **la ligne vide**.

Tout ce qui se trouve entre les deux paires d’astérisques apparaît en gras.

---

## 4. Comparaison avec l’italique

| Effet | Code Markdown | Résultat |
| --- | --- | --- |
| Italique | `*Markdown*` | *Markdown* |
| Gras | `**Markdown**` | **Markdown** |

Un astérisque de chaque côté produit l’italique.

Deux astérisques de chaque côté produisent le gras.

---

## 5. Les astérisques doivent toucher le texte

Écriture correcte :

```markdown
**texte important**
```

Écriture à éviter :

```markdown
** texte important **
```

Ne place pas d’espace entre les astérisques et le texte concerné.

---

## Petit exercice

### Question 1

Écris cette phrase en mettant seulement le mot `Markdown` en gras :

`J’apprends Markdown progressivement.`

### Question 2

Écris cette phrase en mettant l’expression `mon portfolio` en gras :

`Je construis mon portfolio avec soin.`

### Question 3

Explique la différence entre ces deux codes :

```markdown
*texte*
```

```markdown
**texte**
```

---

## À retenir

```markdown
*italique*

**gras**
```

- un astérisque de chaque côté crée l’italique ;
- deux astérisques de chaque côté créent le gras ;
- les astérisques doivent toucher le texte.

Réponds aux trois questions dans la conversation avant de passer au cours suivant.
