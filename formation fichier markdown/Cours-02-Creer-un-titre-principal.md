# Cours 2 — Créer un titre principal

## Objectif

À la fin de ce cours, tu sauras créer le titre principal d’un document Markdown.

Nous apprenons une seule nouvelle notion : le caractère `#` placé devant un texte.

---

## 1. La syntaxe d’un titre principal

Pour créer un titre principal en Markdown, écris :

```markdown
# Mon titre
```

Il faut placer :

1. un seul caractère `#` ;
2. un espace ;
3. le texte du titre.

Dans le code précédent :

- `#` indique à Markdown qu’il s’agit d’un titre principal ;
- l’espace sépare le caractère `#` du texte ;
- `Mon titre` est le texte qui sera affiché.

---

## 2. Code Markdown et résultat affiché

Voici le code que tu écris :

```markdown
# Ma formation Markdown
```

Voici son résultat lorsqu’un lecteur Markdown l’interprète :

# Ma formation Markdown

Le caractère `#` n’apparaît plus comme un caractère ordinaire. Il sert d’instruction pour afficher le texte comme un grand titre.

Cette idée ressemble un peu au HTML :

- tu écris une syntaxe particulière ;
- le logiciel l’interprète ;
- il affiche un résultat structuré.

---

## 3. L’espace est important

Écriture recommandée :

```markdown
# Mon titre
```

Écriture à éviter :

```markdown
#Mon titre
```

Sans espace après le `#`, certains lecteurs Markdown pourraient ne pas reconnaître le titre correctement.

Pour prendre une bonne habitude, écris toujours un espace entre `#` et ton titre.
