## Objectif

---

## 1. Markdown, c’est quoi ?

Markdown est une manière simple d’écrire du texte et de lui donner une structure.

Un fichier Markdown est avant tout un **fichier texte**. Il peut donc être ouvert avec un éditeur de texte comme le Bloc-notes ou Visual Studio Code.

Markdown utilise de petits caractères spéciaux pour indiquer la structure du texte. Par exemple, nous apprendrons plus tard à créer :

- des titres ;
- des paragraphes ;
- des listes ;
- du texte en gras ;
- des liens ;
- des blocs de code.

Pour le moment, il suffit de retenir ceci :

> Markdown permet d’écrire un document structuré avec du texte simple.

---

## 2. L’extension `.md`

Un fichier Markdown se termine généralement par l’extension `.md`.

Exemple :

`mon-premier-fichier.md`

Dans cet exemple :

- `mon-premier-fichier` est le nom du fichier ;
- `.md` est son extension ;
- l’extension indique qu’il s’agit d’un fichier Markdown.

Un fichier nommé `notes.txt` est un fichier texte ordinaire.

Un fichier nommé `notes.md` est un fichier Markdown.

Les deux contiennent du texte, mais un lecteur Markdown peut interpréter la structure écrite dans le fichier `.md` et l’afficher de façon plus jolie.
